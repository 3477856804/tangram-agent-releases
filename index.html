01Core Features

不只是桌宠，是数字生命

从本地推理到 LoRA 微调，从语音合成到 3D 渲染，檀阁瑞木拥有一条完整的生命闭环。

Flutter 界面

左侧边栏导航，JARVIS HUD 质感，与 Python 后端通过 gRPC 完全解耦。

本地 LLM 推理

Qwen2.5 本地模型，纯 CPU 也能跑。模型商店按你的内存自动推荐合适尺寸。

LoRA 微调成长

peft r=4 在 CPU 上训练，适配器保存后，模型会越来越懂你说话的方式。

edge-tts 语音

9 个内置角色各自绑定不同音色，聊天结束后自动语音播报，可随时打断。

3D VRM 展示

model_viewer_plus 渲染 VRM 模型，拖拽旋转，像选英雄一样挑选角色。

自主 Agent 引擎

任务规划 → 工具调用 → 结果观察 → 迭代执行，子 Agent 委派、终端、文件操作、代码搜索全内置。

MCP + 七通道

原生 MCP 协议连接外部工具，打通 Telegram / Discord / 飞书 / WhatsApp / Slack / Signal / Webhook。

插件生态

万物皆插件，定时任务、知识图谱、联网搜索都能装，自己写也行。

10FAQ

你可能想问

关于檀阁瑞木最常见的几个问题。

檀阁瑞木需要联网吗？
不需要。所有模型推理、语音合成、数据存储都在本机完成，断网也能正常聊天。只有「联网搜索」插件会主动请求外部网络，而且默认是关闭的。
我的电脑配置能跑得动吗？
8GB 内存即可流畅运行 Qwen2.5-0.5B；16GB 可以跑 1.5B 并开启 LoRA 训练。模型商店会读取你的可用内存自动推荐最合适的尺寸，不用自己算。
LoRA 训练会不会很慢？
单次训练通常几分钟就能完成，采用 peft r=4 的低秩配置，纯 CPU 也不需要独显。训练好的适配器体积很小，随时可以切换或回滚。
v0.0.2 主要更新了什么？
全新 JARVIS HUD 设计语言，深浅双主题切换；右下角新增快捷操作栏，一键打开工作台、签到、主题、命令面板；左下角新增迷你音景播放器；每日签到可以领取经验奖励。
我可以自己写插件吗？
可以。插件就是一个 Python 文件，实现约定的钩子函数后放进插件目录即可被识别。对话、语音、定时任务、记忆读写都有对应的扩展点。
