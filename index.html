01What's New · v0.0.2

这一版，都是真的

v0.0.2 把「演示」换成了「交付」：每一条都能在 App 里点到。

全平台 OTA 自动更新

App 内检查 GitHub Releases 最新版，分片并行下载，SHA256 清单 + 发布私钥 RSA 签名双重校验，不过签名拒绝安装。Android 调起系统安装器覆盖安装，桌面端落盘更新脚本自动替换重启。

Windows 单文件便携版

49 MB 一个 .exe，双击即运行免安装。内置自解压加载器首次运行释放到 %LOCALAPPDATA%，之后秒开；与安卓发布同一把 RSA 私钥完成 Authenticode 签名。

IM 通道真实打通

QQ、微信、Telegram、WhatsApp 四大平台共 9 个适配器：官方 OpenAPI、扫码桥接、协议直连多路可选，App 内扫码即可登录，消息双向收发带网关状态监控与看门狗。

插件社区上线

插件 / 技能 / MCP 三类扩展统一在插件页发现、安装、卸载，本地池一目了然，启用停用直接映射到后端真实命令。

沙箱执行环境

内置 Debian 沙箱、SSH 远端沙箱、工作区沙箱三选一，CPU / 内存 / 超时隔离配额可编辑落盘，Agent 跑代码不再裸奔。

公告与品牌焕新

App 内接入官网公告 feed，更新日志直达；全套 UI 按 TGA 设计系统重做，深浅双主题，15 个功能页统一视觉语言。

02Core Features

不只是桌宠，是会干活的生命

从本地推理到沙箱执行，从工作痕迹到知识图谱，檀阁瑞木拥有一条完整的「干活—留痕—成长」闭环。

本地 GGUF 推理

GGUF 格式模型本地运行，纯 CPU 也能跑。模型商店内置搜索与仓库探测，按你的磁盘和内存推荐合适量化，下载失败自动重试。

自主 Agent 引擎

任务规划 → 工具调用 → 结果观察 → 迭代执行。每一步都记录为「工作痕迹」，可回放、可追责，不是黑盒。

我的作品

扫描 Agent 真实写文件的工作区，把含产物的目录自动识别为网站 / App / 脚本。网站直接用 WebView 打开你刚生成的页面。

知识图谱

基于真实对话轮次做词共现统计，节点、连线全部来自你的聊天内容，3D 球面排布可旋转查看。她记得你们聊过什么。

沙箱执行

内置 Debian 沙箱 / SSH 远端沙箱 / 工作区沙箱三种环境，配额与超限动作可调可落盘，Agent 的每次执行都在笼子里。

人格系统

多套人格独立命名、独立头像（相册选图即换），默认内置鹿标形象，一键恢复。切换人格即切换说话方式与音色绑定。

22 种中文音色

edge-tts 全量内置 22 个 Neural 音色，语速、音调逐人格可调，聊天结束自动播报，可随时打断。

知识蒸馏

教师模型把优质对话蒸馏成训练素材（6 组蒸馏契约），为后续微调闭环铺路——她的成长有数据，不是玄学。

定时任务

后台调度器按点干活：提醒、巡检、自动跑批。任务在 App 内可视化管理，执行结果进工作痕迹。

10FAQ

你可能想问

关于檀阁瑞木最常见的几个问题。

推理需要联网吗？
模型推理、语音合成、数据存储全部在本机完成，断网也能聊天。需要联网的只有三件事：IM 通道收发消息、OTA 检查更新、以及从模型商店下载 GGUF 模型。
我的电脑配置能跑得动吗？
GGUF 量化模型纯 CPU 就能跑：8GB 内存建议 0.5B–1.5B 小模型，16GB 可上 3B 量化。模型商店会探测你的磁盘与内存，推荐合适的量化尺寸，下载失败自动重试。
QQ / 微信是怎么接进来的？
每个平台都有多条路：QQ 支持官方 OpenAPI 与 OneBot（NapCat）扫码桥接，微信支持 ilink 扫码、公众号 API 与协议直连，Telegram 用 Bot Token，WhatsApp 走 Baileys 扫码桥。App 内「通道」页扫码即可登录，网关带看门狗自动重连。
OTA 更新安全吗？
更新清单由发布私钥做 RSA 签名，App 校验 SHA256 与签名双通过才安装；Android 调起系统安装器覆盖安装，桌面端由更新脚本完成替换与重启。Windows 安装包与安卓 APK 用的是同一把 RSA 私钥。
Windows 提示 SmartScreen 怎么办？
安装包已用发布私钥做 Authenticode 自签名，但自签根证书不在微软信任链里，首次运行会弹提示：点「更多信息」→「仍要运行」即可。校验 SHA256 清单可确认文件未被篡改。
我可以自己写插件吗？
可以。技能 / 插件 / MCP 工具三类扩展共用一个注册中心：插件就是一个实现了约定接口的 Python 文件，放进本地池即可被发现、安装、启停。源码仓库公开，欢迎提 PR。
代码是开源的吗？
源码仓库公开可查（GitHub: tangram-agent），软件版权归 Cosmo 保留所有权利；产物仓库公开全部安装包与校验清单。
