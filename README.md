# tangram-agent-releases

TGA 闭源应用的公开**构建产物**通道，同时承载官网静态页面。

- 各平台 Release 安装包（Windows / macOS / Linux / Android / iOS），供 OTA 检查与下载。
- 官网静态页（`index.html` / `styles.css` / `app.js`）与 Pages Functions（`/dl/*` 下载加速、`/api/announcements` 公告代理）。
- 官网配图为来自 Unsplash 的实拍照片（免费商用），仅作页面视觉使用。

下载链接固定指向 `releases/latest`，发版时无需改动官网，页面不展示版本号。
更新公告固定为「已修复已知问题」。

本仓库不包含任何应用源代码。源代码为专有闭源（All rights reserved）。
